## Administrator path

1. Read [overview](overview.md), [installation](installation.md) or [Portainer](portainer.md).
2. Complete [first steps](first-steps.md), [trunks](trunks-and-numbers.md) and [extensions](extensions-and-devices.md).
3. Check [phones](provisioning.md), [roles](users-and-roles.md) and [routing](call-routing.md).
4. Prepare [backup](backup.md), [monitoring](monitoring.md) and [updates](updates.md).

## User path

1. [Sign in](sign-in.md) and check [My phones](extensions-and-devices.md).
2. Use [softphone](softphone.md), [phone book](phonebook.md) and [call log](call-log.md).
3. Use [voicemail](voicemail.md), [fax](fax.md) and [recordings](recording.md) as permitted.
